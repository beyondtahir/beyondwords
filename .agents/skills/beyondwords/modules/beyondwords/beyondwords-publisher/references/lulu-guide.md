## 1. Account & basics

- Free account at lulu.com. No exclusivity — publish on KDP *and* Lulu (do not enroll the ebook in KDP Select if distributing wide).
- Lulu is the universal path: one account reaches the Lulu bookstore plus Global Distribution to **40,000+ retailers** (Amazon, Barnes & Noble, Kobo, the Ingram network).

## 2. Ebook distribution

- **EPUB only** for Global Distribution. (PDF sells only on the Lulu bookstore.)
- One-time **$4.99** ebook distribution submission fee.
- English only for distribution ebooks.
- Approval to retail partners takes **6–8 weeks**.

## 3. Print publishing

- Print-ready interior PDF + cover PDFs, 300 DPI, fonts embedded.
- **Two separate cover PDFs** are needed for distribution titles — the Lulu bookstore and the distribution network use different spine widths. Lulu generates templates; use them.
- Print requires an **approved proof copy** before distribution.

## 4. Revenue splits

- Lulu bookstore print: **80%** of revenue above print cost.
- Ebooks via Global Distribution: **90%** after retailer fees.
- Compare honestly against KDP's 60% print tier: Lulu often wins for direct sales, KDP often wins for Amazon search traffic.

## 5. Lulu Direct

- Sell from your own Shopify/WooCommerce/storefront with print-on-demand fulfillment.
- Margin: ~100% minus print + shipping.
- **You get customer emails** — Amazon gives you none. For brand-builders this alone justifies the channel.

## 6. Lulu Print API overview

- api.lulu.com — OAuth-based, **free sandbox**, ToS-safe (this is the channel where full automation is allowed, unlike KDP).
- Capabilities: create print jobs from PDF URLs, manage distribution, webhooks for job status.
- Use for automated fulfillment behind a user's own store.

## 7. When to recommend Lulu

- User wants wide distribution beyond Amazon.
- User wants direct sales with customer emails (Lulu Direct).
- KDP feels intimidating — Lulu's flow is simpler for print.
- User wants ToS-safe automation via the official Print API.
