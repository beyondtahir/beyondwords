# Launch and marketing

First establish a useful book, accurate listing, legitimate rights and an affordable experiment. Invite voluntary honest reader feedback; never fabricate reviews, provide rewards for positive reviews or gate requests by sentiment. Source review guidance from current official retailer rules.

Organic content, reader communities and advertisements can be tested using actual outcomes. No universal minimum review count, ad budget or profitability threshold is assumed. Paid ads require explicit account/budget authorization and measured results. Use the current scoped account connectors only with actual access and authorization; recorded plans alone perform no external action.

An income target is a scenario, not a promise: use verified receipts per unit, costs and conversion results. The number of books or months required cannot be inferred from competitor BSR.
