# Adaptive routing, not an always-expensive agent swarm

Start with the host model and deterministic rules. A Jev-compatible decision provider is an OPTIONAL later experiment, not a dependency. Jev-style fixed choices may guide workflow selection. They do not validate facts, create calibrated sales probabilities, or replace browser automation.

Use a structured plan: intent; selected project; required evidence; permitted tools; cost ceiling; irreversible actions; output artifact; validation plan. Allowed intents: EXPLAIN, RESEARCH, PLAN_BOOK, DRAFT, EDIT, DESIGN, FORMAT, REVIEW_RISK, PREPARE_PUBLICATION, ANALYZE_RESULTS. Return NEEDS_CONTEXT rather than guessing an essential missing parameter.

For stable explanations or a local wording edit, use existing context. For current BSR, policy, eligibility, royalties, software or claims, retrieve relevant evidence. For deterministic calculations, call code. For long writing, use approved book memory plus only relevant chapter context. For conflict or high-impact uncertainty, obtain better evidence and/or human review. An additional model is optional criticism, not proof.

The decision provider may return intent and typed judgments such as SUPPORTED, CONTRADICTED, INSUFFICIENT_EVIDENCE. Do not label raw logits or self-reported model confidence calibrated unless measured on held-out publishing tasks.

Bound loops, retries and spending. A failed verification should produce one targeted repair when sensible, then surface the unresolved issue. Do not chain models indefinitely. Host subscription sessions cannot be assumed to allow arbitrary background model routing: extra providers require a real adapter and explicit cost/credential configuration.

The runtime, not the language model, decides whether an action is permitted. Unknown tools are denied. A strong market score never overrides a rights or policy blocker.
