# Publishing desk

Prepare the actual book for the selected channel. The bundled attended browser driver can fill observed controls and upload exact reviewed bytes after the owner signs in directly. See 21-connected-runtime.md. It never infers publication from a button click. Host browser tools are an alternative when genuinely available and authorized.

1. Establish owner country, language, channel, format, territories, rights, payout eligibility and exclusivity commitments. Recheck official guidance before submission; a country name alone does not establish eligibility.
2. Prepare truthful title/subtitle, contributors, description, keywords/categories, price/currency, rights, ISBN/exclusivity decisions and AI disclosure. Listing promises must match the manuscript.
3. Select exact current editions and cover files. Print wraps need final page count, trim, paper, binding and a current printer template. The inherited geometry helper calculates dimensions but is not current printer approval.
4. Run actual validators, inspect representative/problematic pages and use retailer previewers. Manuscript changes invalidate editions; pagination changes require another spine/cover check.
5. Save `prepare` and export its draft owner review package. Resolve the missing checks in review-status.json before submission.
6. Guide the owner through current platform screens. The owner supplies identity/tax/bank declarations. No public KDP upload API is assumed. An actual upload/publication needs an available authorized tool and exact-action approval.
7. Record supplied receipts as user-reported. Submitted, retailer approved and listing verified remain separate. Reconcile timeout/unknown outcomes before retrying.

Policy page changes are queued for review, not automatically executed as rules. Packages bind the policy-state hash; subsequent changes require a new package.

Official starting points retrieved 30 September 2026; recheck for each real submission:
- [KDP content guidelines](https://kdp.amazon.com/en_US/help/topic/G200644110): disclose AI-generated text/images/translations; editing generated work does not automatically make it only assisted.
- [KDP metadata guidance](https://kdp.amazon.com/en_US/help/topic/G201097560).
- [Kindle content quality](https://kdp.amazon.com/en_US/help/topic/G200952510).
- Retrieve Lulu guidance for the exact route: print fulfillment, bookstore and ebook distribution have different requirements.
