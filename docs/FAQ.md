# Questions before you start

[← Back to Beyondwords](../README.md) · [Install](INSTALL.md)

### Is this a prompt collection?

It is a publishing workflow with executable tools: private project records, research evidence, manuscript/version handling, production helpers, account adapters and reporting. The skill tells your assistant when and how to use them. The host still provides the AI and any host-specific tools.

### Do I need publishing experience?

No. Begin with the short intake and one decision at a time. You can also bring an existing manuscript or a published book and start at the relevant stage.

### Is it free?

Beyondwords' original code is MIT-licensed. There is no mandatory Beyondwords subscription, publishing SaaS or paid rank tool. Your assistant, inference, optional image services, printing, advertising and professional services can have separate costs. [Dependencies and licenses](DEPENDENCIES.md) are documented.

### Can it write and illustrate the entire book?

It can help plan, draft, revise and assemble a complete book using the host's available model and image capabilities. It needs your direction and decisions, and the result still needs appropriate editorial and reader evaluation. AI-generated material must be handled and disclosed according to the current platform requirements. There is no promise of human authorship or detector evasion.

### Will it tell me what is profitable or guarantee an income?

It can research observable demand signals, compare competition and reader needs, and build scenarios from explicit inputs. It cannot know future profit, exact search volume or sales from bestseller rank alone. An income target does not establish the number of books, budget or time needed to reach it.

### What if Amazon or another source blocks access?

It records the actual block and uses permitted browsing, another authorized source or an evidence import where available. Missing observations remain unknown. It does not bypass CAPTCHAs, disguise automated access or convert a failed capture into a completed research result.

### Can it publish my book for me?

It can prepare the files and listing, guide account setup and perform supported attended account actions with real access and the scope you authorize. You handle sensitive login, identity, tax, banking and rights declarations directly. Retailer submission, approval and the book going live are separate events. Account acceptance is not guaranteed.

### Can it run and monitor Amazon Ads?

The toolkit includes a Sponsored Products API adapter, campaign workflow, report analysis and monitoring worker. Real operation needs account/API access, explicit spending scope and a running connection. Without API access, import actual reports and use attended actions. Ongoing monitoring needs a configured worker or scheduler; it does not start merely because you installed the skill.

### Does it remember other chats automatically?

It remembers accessible, saved project information in the selected private workspace. It cannot read unrelated chats or automatically synchronize memory between services. Cross-host continuation needs a deliberate handoff and access to the relevant files.

### Does it work in every listed assistant?

The package is portable and the installation guide provides host-specific routes. Available tools, local execution, persistent storage, import controls and account connections differ. Run the first-use check in your actual environment. Documentation compatibility is not the same as end-to-end acceptance testing.

### Can I use a local model?

The local toolkit makes no model API calls, so the AI interface can be replaced. A documented, tested local-inference path is a future release requirement; no model or validated local-model setup is bundled today.

### What should I share in a bug report?

Use [GitHub Issues](https://github.com/beyondtahir/beyondwords/issues). Include the version, host, operating system, intended action, actual result and a minimal non-private example. Remove credentials, account identifiers, cookies, manuscripts and private paths. Avoid uploading complete project state by default.
